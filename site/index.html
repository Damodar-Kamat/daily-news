    Connect the refresh button

    The ⟳ button asks GitHub to fetch fresh news right now. It needs a GitHub token that can only run the update job of this one repository.

    1. Open this pre-filled GitHub token form (name, 1-year expiry and Actions: Read and write are filled in).
    2. Repository access: Only select repositories → daily-news.
    3. Check Permissions shows Actions: Read and write and Metadata: Read-only (added automatically), nothing else.
    4. Click Generate token, copy it (starts with github_pat_) and paste it below.

    It is saved only in this browser on this device and sent only to api.github.com. You can delete it anytime here or on GitHub.
